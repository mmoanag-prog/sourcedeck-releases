# SourceDeck cho Windows

Ứng dụng kiểm tra kênh/video và tải video dùng cho Premiere. Bộ tải tích hợp sẵn, không cần mở Helper hoặc tự chạy localhost.

## Tải ứng dụng

[**Tải bản mới nhất**](https://github.com/mmoanag-prog/sourcedeck-releases/releases/latest) → chọn file `SourceDeck-…-Setup-x64.exe` trong Assets. Windows 10/11 64-bit; không cần đăng nhập GitHub.

## Cập nhật

Từ bản 1.4: **Cài đặt → Cập nhật → Kiểm tra cập nhật → Tải bản cập nhật → Cập nhật và mở lại**. Chờ các video đang tải hoàn thành trước khi cài. App lưu và sao lưu dự án trước khi cập nhật.

Nếu đang dùng Portable 1.3, cài bản Setup mới một lần rồi mở từ Desktop/Start Menu. Dữ liệu cùng tài khoản Windows được giữ tại `%APPDATA%\SourceDeck`. Dữ liệu từ AI Studio cần Xuất JSON rồi Nhập JSON trong ứng dụng.

Mỗi người dùng dự án, API key và thư mục video riêng trên máy; app không tự đồng bộ dữ liệu. Lần đầu, nhập YouTube Data API key của mình trong Cài đặt → API.

## Nội dung kho này

Chỉ lưu bộ cài, thông tin cập nhật và hướng dẫn. Không chứa dự án người dùng, API key hoặc bản mã nguồn dự án riêng. Bất kỳ ai có đường dẫn đều có thể tải bộ cài.

Bộ cài hiện chưa có chứng thư ký số của nhà phát hành; Windows có thể hiện thông báo xác minh nguồn gốc.
